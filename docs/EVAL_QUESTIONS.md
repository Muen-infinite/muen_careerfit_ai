# EVAL_QUESTIONS.md — CareerFit AI 자기 평가 질문



## 이 질문들에 스스로 답할 수 있어야 최종 발표와 면접에 나설 수 있다.



## 프로젝트 전체

- 이 서비스가 해결하는 문제는 무엇인가?
이 서비스는 취업 준비생이 자신의 역량과 채용 공고를 효과적으로 연결하기 어려운 문제를 해결하기 위해 만들어졌습니다.

- RAG를 사용하지 않으면 어떤 문제가 생기는가?
RAG를 사용하지 않으면 AI가 실제 채용 공고가 아닌 자신의 학습 내용만으로 답변하여 부정확하거나 근거 없는 정보를 생성할 가능성이 커집니다.

- 가장 어려웠던 구현은 무엇이고, 어떻게 해결했는가?



## 데이터 관련

- 왜 이 데이터를 선택했는가?
 시간제약이 있는 프로젝트이기 때문에 강의 자료에 있는 데이터를 사용했다.

- 데이터의 어떤 부분이 신뢰할 수 없을 수 있는가?
강의에서 제공한 목업 데이터이기 때문에 실제 채용 시장을 완벽하게 반영하지 않을 수 있다는 점이 가장 큰 한계입니다.

- SQLite와 ChromaDB에 같은 데이터를 저장하는 이유는 무엇인가?
SQLite와 ChromaDB는 역할이 다르기 때문에 같은 데이터를 저장합니다. SQLite는 정확한 조회와 관리, ChromaDB는 의미 기반 검색(RAG) 을 담당합니다.

- 결측치와 중복을 어떻게 처리했는가?
결측치는 분석에 필요한 핵심 정보가 없는 데이터는 제거했고, 중복은 같은 회사와 같은 공고가 반복된 경우 하나만 남기도록 처리했습니다.



## RAG 관련

- RAG 구조에서 ChromaDB는 어떤 역할을 하는가?
ChromaDB는 사용자의 질문과 의미가 비슷한 채용 공고를 찾아 LLM(Gemini)에 전달하는 역할을 합니다. 즉, RAG에서 의미 기반 검색(Vector Search) 을 담당합니다.

- n_results 값을 높이면 어떤 트레이드오프가 생기는가?
관련성이 낮은 문서까지 포함되어 답변 품질이 떨어질 수 있습니다

- 검색 결과 품질을 어떻게 검증했는가?
검색 결과는 관련성, 근거성, 출처 표시의 세 가지 기준으로 검증했습니다. 또한 ChromaDB의 distance 값을 확인하여 검색 품질을 평가했습니다.

- Hallucination이 무엇이며, RAG가 이를 어떻게 줄이는가?
Hallucination(환각)은 LLM이 사실이 아닌 정보를 마치 사실처럼 생성하는 현상입니다. RAG는 검색된 실제 데이터를 함께 제공하여 이러한 현상을 줄여줍니다.

## API 관련

- /analyze 엔드포인트가 POST를 사용하는 이유는 무엇인가?
/analyze는 사용자의 전공, 보유 기술, 희망 직무 등 여러 데이터를 요청 본문(JSON)으로 받아 분석해야 하기 때문에 POST를 사용합니다.

- 응답 JSON에 sources를 포함시킨 이유는 무엇인가?
응답 JSON에 sources를 포함한 이유는 AI가 어떤 채용 공고를 근거로 답변했는지 사용자에게 보여주어 답변의 신뢰성과 검증 가능성을 높이기 위해서입니다.

- /health 엔드포인트가 왜 필요한가?
/health 엔드포인트는 서버가 정상적으로 실행되고 있는지 빠르게 확인하기 위한 API입니다. 개발과 배포 과정에서 서버 상태를 점검하는 용도로 사용합니다.



## 보안 관련

- .env 파일을 GitHub에 올리면 어떤 일이 생기는가?
.env 파일을 GitHub에 올리면 API Key와 같은 민감한 정보가 공개되어 보안 사고가 발생할 수 있습니다. 특히 Gemini API Key는 노출되면 악용되거나 비활성화될 수 있습니다.

- .env와 .env.example의 차이는 무엇인가?
.env는 실제 환경변수(API Key 등)를 저장하는 파일이고, .env.example은 어떤 환경변수가 필요한지 알려주는 템플릿 파일입니다.



## Docker 관련

- Docker를 사용하는 이유는 무엇인가?
Docker를 사용하는 이유는 어떤 컴퓨터에서 실행하더라도 동일한 개발 환경과 실행 결과를 보장하기 위해서입니다.

- Dockerfile에서 EXPOSE와 CMD의 역할은 무엇인가?
EXPOSE는 컨테이너가 사용할 포트를 알려주는 역할이고, CMD는 컨테이너가 시작될 때 실행할 기본 명령어를 지정하는 역할입니다.
